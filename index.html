Comment importer les ranges ?
  1. Téléchargez MesRanges-Pack-100BB.zip.
  2. Ouvrez l'application Poker Toolkit.
  3. Depuis la page d'accueil, sélectionnez Importer.
  4. Sélectionnez le fichier ZIP du pack 100 BB que vous venez de télécharger.
  5. Validez l'import : les 54 ranges sont alors ajoutées à Mes Ranges.
  6. Ouvrez le module Ranges pour consulter et travailler les ranges importées.
Le fichier doit rester au format ZIP pour l'import : il n'est pas nécessaire de le décompresser avant de le sélectionner dans Poker Toolkit.
